# Khan Muhammad Ahsan — Personal Portfolio

> **Software Engineer & AI Startup Founder** based in Suwon, South Korea.  
> Global Korea Scholarship (GKS) Fellow at Ajou University & CEO at [Preplit AI](https://preplitai.com).

A personal portfolio website featuring a Swiss editorial design system inspired by [Alex Tkachev](https://alextkachev.com). Built with high-contrast typography, an asymmetric 16-column layout, dual Warm Editorial / Onyx Studio themes, a live Suwon status clock, and full mobile responsiveness.

---

## ✨ Features

- **Swiss Editorial Aesthetic**: Distinctive serif and grotesque typography pairing (`EB Garamond` + `Helvetica Now Display`), minimalist hairline dividers, and spacious negative space.
- **Dual Aesthetic Themes**:
  - **Warm Editorial (Default)**: `#F8F8F6` background with rich off-black `#050505` text.
  - **Onyx Studio (Dark Mode)**: `#0B0B0C` deep black background with high-legibility `#F2F2F0` text.
  - State persisted seamlessly in `localStorage` with automated system theme matching.
- **Live Suwon, South Korea Status Clock**: Real-time KST clock (`Asia/Seoul`, UTC+9) with a pulsing availability indicator.
- **Ventures & Projects**:
  - **Preplit AI** — AI-powered education workspace and multi-agent reasoning system.
  - **CampusRank** — Global student and university competitive ranking platform.
  - **Resumate** — AI platform performing deep resume analysis and ATS scoring.
  - **Covenant & Co** — Luxury watch e-commerce storefront (100k+ visitors) and B2B China/Korea supply chain.
  - **Autonomous Screen Bot** — OpenCV computer vision & sub-pixel screen automation engine.
  - **TextVision OCR** — Cloud vision document text extraction pipeline with Flask REST API.
- **ATS-Ready Web CV**: Printable curriculum vitae at [`cv.html`](./cv.html) with clean `@media print` rules and a 1-click **"Print / Save PDF"** action.
- **Tactile Micro-Interactions**: Smooth GSAP entrance animations, directional hover underlines, and a 1-click email copy button with toast feedback.
- **100% Mobile Responsive**: Zero horizontal overflow with fluid `clamp()` typography and stacked layouts across phones and tablets.

## 🛠️ Tech Stack

- **Markup & Styling**: Semantic HTML5, CSS3 Custom Properties (Variables), Responsive Grid & Flexbox
- **Typography**: Helvetica Now Display, EB Garamond (WOFF2)
- **Animations**: GSAP 3 & ScrollTrigger
- **Asset Tools**: Python & PIL (Pillow) for automated image generation and asset pipelines

## 🚀 Running Locally

You can preview the site with any static web server:

### Using Python:
```bash
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

### Using Node / npx:
```bash
npx serve .
```
